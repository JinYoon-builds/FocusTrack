# Troubleshooting: Numpy Dimensions & Flattening
<b>Date:</b> 2025-12-28
<b>Related Issue:</b> #9

## 1. Situation (상황)
MediaPipe에서 추출한 랜드마크 데이터를 모아보니 `(30, 7, 2)` 형태의 3차원 배열(Array)이었음.
* `30`: 프레임 수 (Time)
* `7`: 신체 포인트 개수 (Nose, Eyes, etc.)
* `2`: 좌표 (x, y)
이 데이터를 그대로 `np.cov()` 함수에 넣자 `ValueError`가 발생하거나, 의도와 다른 통계치가 계산됨.

## 2. Task (과제)
Scikit-learn이나 Numpy 같은 라이브러리가 이해할 수 있는 <b>표준 데이터 포맷(Standard Data Format)</b>으로 변환해야 함.

### 🤔 표준 포맷이란? (The "Excel" Rule)
모든 통계 라이브러리는 데이터를 **"2차원 엑셀 표"** 형태로 받기를 원함.
$$X = (N_{samples}, D_{features})$$

* <b>행(Row, $N$):</b> 데이터의 개수 (건수). 여기서는 **"각 프레임(순간)"**.
* <b>열(Column, $D$):</b> 분석하고 싶은 변수 항목. 여기서는 **"각 관절의 좌표값"**.

**문제점:** 현재 데이터 `(7, 2)`는 변수 항목이 2차원(층과 방)으로 꼬여 있어서, 컴퓨터가 "그래서 변수가 7개야, 2개야?"라고 헷갈려 함.

## 3. Action (해결책)
<b>Flattening (평탄화)</b> 전처리를 수행함.

* <b>접근:</b> 한 프레임 내의 모든 좌표점(7개 점 * 2좌표 = 14개 숫자)을 <b>한 줄로 길게 펴서</b> 14개의 독립된 변수(Column)로 만듦. 정보 손실은 없으며, 데이터의 **배치(Layout)**만 변경함.
* <b>적용:</b> `.flatten()` 메서드 사용.
    * <b>Before (3D):</b> `[[코x, 코y], [눈x, 눈y], ...]` $\rightarrow$ (방 7개 x 침대 2개)
    * <b>After (2D):</b> `[코x, 코y, 눈x, 눈y, ...]` $\rightarrow$ (침대 14개 일렬배치)

## 4. Result (결과)
* 데이터 형태가 `(30, 14)`의 <b>완벽한 2차원 행렬</b>로 변환됨.
* `np.cov` 함수가 이를 <b>"14개의 변수(특징)를 가진 30개의 데이터 샘플"</b>로 정확히 인식함.
* <b>데이터의 순서(Order)</b>가 일정하게 유지되므로, 넘파이가 "0번 변수(코X)와 2번 변수(눈X)의 움직임 패턴"인 공분산을 정확하게 계산해 냄.
    * <i>(Note: 넘파이가 변수의 의미(코, 눈)를 이해하는 것은 아니며 중요하지도 않음. 단지 **고정된 인덱스(Index)에 들어오는 숫자들 간의 수치적 관계**를 계산할 뿐임.)</i>
